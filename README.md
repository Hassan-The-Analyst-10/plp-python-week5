# Assignment: Countdown, Guessing Game & Loop Patterns

This assignment practices `while` loops, `for` loops, conditionals, counters, and repetition in Python.

## Files

- `countdown.py` - Uses a while loop to count down from a number and print "Blast off!".
- `guess_game.py` - Creates a guessing game with hints, a while loop, and an attempt counter.
- `spell_it_out.py` - Uses for loops to print and number each letter of a word.
- `screenshots/` - Contains screenshots showing the required program runs.

## When would you use a while loop instead of a for loop?

A `while` loop is useful when you want to keep repeating something until a condition becomes false, especially when you do not know exactly how many repetitions are needed. A `for` loop is better when you want to go through a known sequence or collection, such as each letter in a word or a range of numbers.
